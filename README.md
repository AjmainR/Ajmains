# AJMAIN — Cyber Security Portfolio

A high-tech, animated, dynamic personal portfolio website for **AJMAIN**, a Class 9 student from Bangladesh passionate about Cyber Security, Ethical Hacking, Coding, AI, and Music.

## Features

- **Dark Cyber Theme** — Neon green & cyan accents on deep dark background
- **Particle Network Background** — Interactive canvas particles that react to mouse
- **Glitch Text Effect** — On the main name
- **Typing Animation** — Rotating professional taglines
- **Smooth Scroll & Reveal Animations**
- **Skill Progress Bars** — Animated on scroll
- **Timeline Journey** — Visual career path
- **Direct Contact Form** — Opens email client with pre-filled message
- **Social Links** — Facebook, Instagram, GitHub, Email
- **Fully Responsive** — Mobile-friendly with hamburger menu
- **Scanline Overlay** — Subtle CRT-style effect

## How to Use

1. Open `index.html` in any modern browser.
2. Or deploy the folder to GitHub Pages, Netlify, Vercel, etc.

## Files

- `index.html` — Structure
- `styles.css` — All styling & animations
- `script.js` — Particles, typing, interactions
